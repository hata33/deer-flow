基础入门

⭐ 初级

Step 1.1 · 项目认知

理解 DeerFlow 的定位：基于 LangGraph 的 AI 超级 Agent，支持沙箱执行、持久记忆、子代理委派、可扩展工具集成。

  • 读 README.md 了解功能全貌
  • 读 backend/CLAUDE.md 理解架构概览
  • 理解三层服务：Gateway(8001) + Frontend(3000) + Nginx(2026)

Step 1.2 · 环境搭建

本地跑通项目。

  • Python 3.12+ / Node.js 22+ / pnpm 10.26+
  • make check → make install → make dev
  • 访问 http://localhost:2026 验证

Step 1.3 · 配置体系

两个核心配置文件，决定 agent 的能力边界。

  • config.yaml — 模型、工具、沙箱、记忆等
  • extensions_config.json — MCP 服务器 + Skills 启用状态
  • 配置优先级：DEER_FLOW_CONFIG_PATH → 当前目录 → 父目录
  • 热重载机制：基于 mtime 检测变更

Step 1.4 · 首次完整对话

端到端体验一次 agent 对话，观察流式输出、工具调用、记忆生成。

  • 配置至少一个 LLM 模型（OpenAI 兼容 / DeepSeek / Qwen 等）
  • 发送消息 → 观察 SSE 流式响应
  • 触发工具调用（如 bash 命令）→ 观察沙箱执行

Step 2.1 · 分层设计（Harness / App Split）

最关键的架构概念：严格的依赖方向。

  • Harness（packages/harness/deerflow/）— 可发布的 agent 框架，导入前缀 deerflow.*
  • App（app/）— 不可发布的应用代码，导入前缀 app.*
  • 规则：App 可以 import deerflow，但 deerflow 永远不能 import app
  • 由 tests/test_harness_boundary.py 强制约束

Step 2.2 · Gateway API

FastAPI 应用层，提供 REST + SSE 接口。

  • 入口：app/gateway/app.py
  • 认证链：CORS → CSRF → JWT
  • 关键路由：threads / runs / models / skills
  • LangGraph 兼容：/api/langgraph/* → Gateway 原生 /api/*

Step 2.3 · Runtime 运行时

Agent 执行的核心引擎。

  • RunManager — 管理运行生命周期（创建/取消/状态）
  • StreamBridge — 将 LangChain 事件桥接到 SSE
  • run_agent() — 执行入口（runtime/runs/worker.py）
  • RunStore — 持久化运行记录（内存/SQL）

Step 2.4 · 数据流

跟踪一次请求的完整流转（参考 data-flow.html）。

  • 用户 → Frontend → Nginx → Gateway → RunManager → Agent → LLM
  • Token 流 → StreamBridge → SSE → Frontend 实时渲染
  • Checkpoint 持久化线程状态

Step 3.1 · LangGraph 图结构

DeerFlow 基于 langchain.agents.create_agent 构建 ReAct Agent。

  • 入口：lead_agent/agent.py::make_lead_agent
  • 图节点：model node（LLM）+ tools node（工具执行）
  • 条件路由：有 tool_calls → tools node，无 → END
  • 状态：ThreadState（扩展 AgentState）

Step 3.2 · 中间件链（核心重点）

19 个中间件分四类 hook，严格按顺序执行。

  • before_agent — 一次性准备（沙箱、目录、上传文件）
  • wrap_model_call — 包裹每次 LLM 调用（重试、安全、上下文注入）
  • after_model — LLM 响应后处理（用量、标题、记忆、循环检测）
  • wrap_tool_call — 包裹工具调用（审计、错误处理）
  • ⭐ 学习建议：逐个读 agents/middlewares/ 下的实现

Step 3.3 · 工具系统

四类工具按优先级装配。

  • Config Tools（config.yaml）→ MCP Tools → Builtin Tools → SubAgent Tools
  • 内置：bash / read_file / write_file / view_image / ask_clarification
  • 装配入口：tools/tools.py::get_available_tools

Step 3.4 · 沙箱机制

工具执行的隔离环境。

  • LocalSandbox — 本地文件系统 + 路径映射
  • AioSandbox — Docker 容器隔离
  • 虚拟路径：/mnt/user-data/{workspace,uploads,outputs}
  • 物理路径：.deer-flow/users/{uid}/threads/{tid}/

高级专题

⭐⭐⭐⭐ 专家
🤖

子代理系统

任务委派机制。LeadAgent 可通过 task() 工具委派给子代理（general-purpose / bash），双线程池调度，最大并发 3。

SubagentExecutor _scheduler_pool SubagentLimitMiddleware
🧠

记忆系统

LLM 驱动的事实提取 + 按用户隔离存储。去抖队列（30s）→ 后台 LLM 提取 → 原子写入 → 注入 System Prompt。

MemoryMiddleware MemoryUpdateQueue per-user
🔌

MCP 集成

Model Context Protocol 外部工具。支持 stdio / SSE / HTTP 传输，OAuth 认证，mtime 缓存失效，延迟绑定（tool_search）。

MultiServerMCPClient DeferredToolFilter OAuth
💬

IM 通道集成

飞书/Slack/Telegram/Discord/钉钉。通过 langgraph-sdk HTTP client 与 Gateway 通信，支持流式卡片更新。

ChannelManager MessageBus runs.stream
💾

持久化层

Checkpointer 状态持久化 + RunEventStore 运行事件存储。支持内存/SQLite/PostgreSQL 后端，支持事务和多 worker。

Checkpointer RunEventStore SqliteSync
📦

Skills 系统

SKILL.md 定义的可复用能力。Frontmatter 元数据 + 安全扫描 + 斜杠激活（/skill-name task）+ .skill 归档安装。

SKILL.md SkillActivation LocalSkillStorage
🔗
